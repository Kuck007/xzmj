这是我用ai写的一个自用的美甲工作室自用的管理系统，我会长期维护。并解决问题。本人完全不会编程，完全使用的是对话式生成的内容。
首先，这是用traework写的，由我用xcode实际对每个功能进行测试，也是我实际工作中使用的软件，过程中并由ai对bug修改，增加新功能，1.4.3版本是我多次迭代得到的产物。
本人对这个系统还算满意，也是第一次上传内容。
在工作过程中，也会不断对这个程序进行修改，增加并完善我可能使用的功能。
现在只有mac版本是因为，我使用一台mac mini 挂远程比较省电，所以，也没有考虑到win平台，用的还是mac的内置持久化数据库，未来还有很多路要走。
